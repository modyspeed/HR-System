# P6 — الاستيراد (Excel ثم PDF)

> **التصميم والمعمارية:** التزم بـ DESIGN_SYSTEM.md (كل شاشة تشتغل Light وDark وRTL، توكنز فقط) وبـ ARCHITECTURE_MODULES.md (الكود يتحط في وحدته وبيتسجل في registry). أرفق لقطة/وصف للشاشة في الوضعين في التقرير.

المدخلات: الكود الحالي (P5 مقبولة) + SPEC_COMPACT.md (قسم الاستيراد)
قسّمها لجلستين لو لزم: P6a Excel، P6b PDF.
P6a (Excel):
1. قالب Excel قابل للتحميل من البرنامج (الأعمدة: الكود، الاسم، القسم، المسمى، تاريخ التعيين، الرقم القومي، الهاتف).
2. معالج: اختيار ملف → معاينة أول 50 صف → ربط الأعمدة → فحص (كود مكرر، تاريخ غلط، اسم فاضي) → اختيار (تخطي/تحديث للمكرر) → تأكيد.
3. الكتابة في transaction واحدة؛ صف خطأ لا يوقف الباقي (يتسجل) أو خيار "إلغاء الكل".
4. import_batches + تقرير نهائي قابل للتصدير.
P6b (PDF):
1. استخراج نص PDF النصي بـ pdfjs وإعادة بناء الصفوف بالإحداثيات (مع مراعاة RTL)، ثم نفس معالج الربط والمعاينة.
2. PDF ممسوح (بدون نص) → رسالة "الملف صورة، استخدم Excel".
شروط القبول: استيراد 200 صف وهمي، تواريخ بالصيغ الثلاث، مكرر، صف خطأ، كلها تتعامل صح. معاينة إجبارية قبل الحفظ.
