# P4 — ملفات الموظف (PDF) واستمارة الإجازة

> **التصميم والمعمارية:** التزم بـ DESIGN_SYSTEM.md (كل شاشة تشتغل Light وDark وRTL، توكنز فقط) وبـ ARCHITECTURE_MODULES.md (الكود يتحط في وحدته وبيتسجل في registry). أرفق لقطة/وصف للشاشة في الوضعين في التقرير.

المدخلات: الكود الحالي (P3 مقبولة) + SPEC_COMPACT.md (قسم ملفات الموظف)
المطلوب:
1. services/fileLinker.ts: تحديد فولدر الموظف، إنشاؤه، مسح محتواه، ربطه بجدول employee_documents، مسارات نسبية فقط، حماية من path traversal (لا خروج خارج employee_files).
2. تاب "ملف الموظف (PDF)": شجرة (ملفات + leaves + decisions)، معاينة PDF داخل البرنامج (pdfjs: صفحات/تكبير/طباعة)، زر رفع ملف (نسخ للفولدر، منع تكرار الاسم بإضافة رقم)، زر فتح الفولدر في الجهاز (shell.openPath)، حالة "لا يوجد ملف" + إنشاء الفولدر.
3. زر "مزامنة الملفات" في صفحة الموظفين + تقرير فولدرات بأكواد غير معروفة.
4. استمارة الإجازة: رفع PDF أو صورة في شاشة طلب الإجازة (يتحفظ في leaves/ ومربوط بـ related_leave_id)، وتاب "الإجازات والاستمارات" في ملف الموظف فيه الطلبات + أيقونة الاستمارة + رفع/استبدال.
5. ربط شرط requires_attachment: الاعتماد يتطلب وجود استمارة.
شروط القبول:

- [ ] لا مسارات مطلقة في القاعدة
