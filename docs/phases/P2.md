# P2 — الموظفين وملف الموظف (تاب البيانات)

> **التصميم والمعمارية:** التزم بـ DESIGN_SYSTEM.md (كل شاشة تشتغل Light وDark وRTL، توكنز فقط) وبـ ARCHITECTURE_MODULES.md (الكود يتحط في وحدته وبيتسجل في registry). أرفق لقطة/وصف للشاشة في الوضعين في التقرير.

المدخلات: الكود الحالي (P1b مقبولة) + SPEC_COMPACT.md + SCHEMA.sql
المطلوب:
1. IPC + خدمات: قائمة الموظفين (بحث بالاسم/الكود + فلتر قسم)، إضافة، تعديل، تغيير status (حذف ناعم)، الأقسام (إضافة/قائمة).
2. صفحة الموظفين: جدول (الموظف، الكود، القسم، تاريخ التعيين، أرصدة اعتيادي/عارضة كأعمدة مبدئية = الاستحقاق حاليًا)، بحث، فلتر، زر موظف جديد (نموذج + zod).
3. صفحة EmployeeProfile بالهيدر وتاب "البيانات" فقط (عرض/تعديل). باقي التابات موجودة بعنوان "قريبًا".
4. التحقق: الكود فريد، تاريخ التعيين صحيح، الاسم مطلوب. رسائل خطأ عربية واضحة.
5. audit_log على الإضافة والتعديل.
شروط القبول:
- [ ] إضافة/تعديل/إيقاف موظف والبيانات تفضل بعد إغلاق وفتح البرنامج
- [ ] البحث والفلتر شغالين
- [ ] كود مكرر يرفض برسالة عربية
- [ ] تأكيد قبل الإيقاف
ممنوع: حساب إجازات أو رفع ملفات (مراحل لاحقة).
