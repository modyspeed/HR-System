# P7 — الإعدادات والتشطيب والمثبّت

> **التصميم والمعمارية:** التزم بـ DESIGN_SYSTEM.md (كل شاشة تشتغل Light وDark وRTL، توكنز فقط) وبـ ARCHITECTURE_MODULES.md (الكود يتحط في وحدته وبيتسجل في registry). أرفق لقطة/وصف للشاشة في الوضعين في التقرير.

المدخلات: الكود الحالي (P6 مقبولة)
المطلوب:
1. شاشة الإعدادات (أقسام: عام، المظهر [ثيم system/light/dark + طي الشريط الجانبي]، الأرصدة، العطلات، الملفات، النسخ الاحتياطي، الوحدات [تفعيل/تعطيل]): مسار employee_files، بادئة الكود، أيام العطلة الأسبوعية، حد التنبيه، أنواع الإجازات وأرصدتها (تعديل)، العطلات الرسمية (إضافة/حذف)، قاعدة اختيارية لرفع الاعتيادي بعد X سنة خدمة أو سن Y.
2. "تجهيز أرصدة سنة جديدة" مع ترحيل اختياري بسقف.
3. نسخ احتياطي واسترجاع (leavedesk.db + اختياري employee_files) بتاريخ.
4. تصدير Excel: الموظفين والأرصدة، سجل الإجازات، القرارات.
5. docs/USER_GUIDE.md بالعربي.
6. electron-builder: مثبّت Windows .exe يشتغل على جهاز نضيف.
شروط القبول: المثبّت يتثبت ويفتح، استرجاع نسخة احتياطية يرجّع البيانات، التصدير يفتح في Excel بعربي سليم.
