# رسالة المنصة — المرحلة P1a (الصقها كأول رسالة، ثم أرفق الملفات)

---
أنت مهندس برمجيات. هننفذ مشروع ديسكتوب اسمه **LeaveDesk** على مراحل، وأنت هتنفذ دلوقتي **المرحلة P1a فقط**. مفيش عندك تاريخ محادثة، فالمصدر الوحيد للحقيقة هو الملفات المرفقة. اقرأها كلها قبل ما تكتب أي كود.

## الملفات المرفقة
1. docs/SPEC_COMPACT.md — المواصفات (التقنيات، الهيكل، القواعد)
2. docs/ARCHITECTURE_MODULES.md — معمارية النواة والوحدات
3. docs/SCHEMA.sql — قاعدة البيانات بالظبط
4. docs/PROJECT_STATE.md — حالة المشروع
5. docs/phases/P1a.md — مهمتك وشروط القبول
6. صور مرجعية (لو مرفقة): docs/reference/meta_*.pdf مرجع وظيفي فقط، وdocs/reference/target_*.png هدف بصري للمراحل الجاية. لا تنفذ تصميم متقدم في P1a.
المستودع (عام): https://github.com/modyspeed/HR-System — الملفات أعلاه موجودة في مجلد docs/ فيه. لو بتقدر تفتح الرابط اقرأها منه، ولو لأ فهي مرفقة.

## قواعد إلزامية
- ابدأ بملخص من 3 أسطر: فهمت المشروع إزاي، وهتنفذ إيه بالظبط دلوقتي. ثم نفّذ.
- نفّذ P1a فقط. لا تنتقل لأي مرحلة بعدها ولا تبني شاشات وظيفية.
- التقنيات ثابتة: Electron + React + Vite + TypeScript + Bootstrap 5.3 RTL + SQLite (better-sqlite3). لا تغيّرها، ولا تغيّر أسماء الجداول والأعمدة.
- لو شايف تعديل ضروري اكتبه في "اقتراحات" في التقرير ولا تنفذه.
- أمان Electron: contextIsolation=true وnodeIntegration=false، والوصول للملفات وقاعدة البيانات عبر IPC في preload بقنوات محددة.
- بدون CDN وبدون إنترنت وقت التشغيل.
- اكتب كل ملف **كاملًا** (ممنوع "..." أو "باقي الكود كما هو").
- لو غامض شيء: افترض أبسط حل واكتب الافتراض في التقرير.
- لو الجلسة هتخلص قبل ما تكمل: وقف عند أقرب ملف مكتمل وسجّل بالظبط وقفت فين.
- بيانات الاختبار وهمية فقط.
