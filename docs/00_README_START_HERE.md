## اللي تبعته لأي منصة جديدة (3 حاجات بس عشان السياق الصغير)
1. RESUME_PROMPT.md
2. SPEC_COMPACT.md + PROJECT_STATE.md
3. ملف المرحلة الحالية من phases/ (ولو المرحلة محتاجة SCHEMA.sql ابعته معاها)
   - مرحلة فيها واجهة: ضيف DESIGN_SYSTEM.md. مرحلة بتضيف/تعدل وحدة: ضيف ARCHITECTURE_MODULES.md.
+ الكود نفسه (انظر تحت).

## الكود هو المرجع الحقيقي
المنصات المجانية بتضيّع الجلسات والملفات، فاعمل واحدة من دي:
- **الأفضل:** مستودع GitHub خاص (Private). المنصة تعمل commit بعد كل مرحلة بالرسالة `P3: leave calculator done`، والمنصة الجاية تعمل clone وتكمل.
- **بديل:** ZIP للمشروع كله (بدون node_modules) بعد كل مرحلة، وتحفظ نسخة على جهازك بالاسم `LeaveDesk_P3_2026-10-05.zip`.
- لو المنصة مش بتقدر ترفع ملفات: خليها تطبع الملفات الجديدة/المعدلة كاملة، وانت تحطها في مكانها.

## دورة الشغل (كل جلسة)
1. افتح منصة، ابعتلها الحزمة الثلاثية + الكود.
2. تنفذ المرحلة وتخلص بـ **تقرير الجلسة** بالصيغة الموجودة في RESUME_PROMPT.md.
3. ابعتلي (Claude) التقرير + الكود/الملفات المعدلة.
4. أنا أراجع وأديك: (أ) تعليمات تصحيح تبعتها للمنصة، (ب) PROJECT_STATE.md و SESSION_LOG.md محدّثين.
5. احفظ النسخة المحدثة من التوثيق في نفس الفولدر، وكرر.

## قواعد ذهبية
- منصة جديدة = **ماتغيّرش** التقنيات أو أسماء الجداول إلا بقرار مسجل في DECISIONS.md.
- مرحلة واحدة في الجلسة. لو الجلسة وقفت في النص، التقرير يقول بالظبط وقفت عند أي ملف.
- متبعتش للمنصة بيانات موظفين حقيقية للاختبار. استخدم بيانات وهمية.
